# Генераторы воркфлоу

Воркфлоу n8n собираются скриптами, а не правятся руками. Результат пишется в `infra/files/workflows/`.

- `gen01.py` подключение аккаунтов (01), `gen03.py` консольный API (03), `gen04.py` ручная публикация из папки (04), `gen05.py` API панели (05), `gen06.py` планировщик и слоты (06, 07, 08).
- `blocks.py`, `snippets.py` общие куски кода (авторизация, шифрование токенов, блокировки, загрузка в TikTok).
- `templates/` исходные шаблоны, из которых берутся узлы.

Сборка: `python tools/genNN.py`. Проверка синтаксиса кода узлов: выгрузить `jsCode` и прогнать `node --check`. Деплой: см. `docs/SETUP_WORKFLOWS.md`.
