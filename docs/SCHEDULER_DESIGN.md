# Расписание публикаций: дизайн

Статус: реализовано (воркфлоу 06, 07, 08 и вкладка Schedule в панели); проверено в тестовом режиме без отправки в TikTok. Масштаб: 50-300 аккаунтов, ПК работает 24/7.

## Решения
- **Время:** случайное внутри окон (например 09:00-22:00) с минимальным интервалом между постами аккаунта.
- **Профили:** один профиль расписания на группу аккаунтов, у аккаунта можно переопределить (число постов, пауза, окна).
- **Пропущенные слоты** (ПК был выключен): наверстать, если опоздание меньше N часов (по умолчанию 6), иначе пропустить.
- **Масштаб:** 50-300 аккаунтов, 1-3 поста в день. Тяжёлая часть (ffmpeg, хук, музыка) готовится заранее, в момент слота остаётся только загрузка в TikTok.

## Данные
`infra/files/schedule.json`:
- `global`: `paused`, `catchup_hours`, `max_parallel` (одновременных загрузок, по умолчанию 2), `prepare_ahead_hours` (по умолчанию 12), `pause_after_errors` (по умолчанию 3).
- `profiles`: имя -> `posts_per_day`, `windows` (список пар "ЧЧ:ММ"), `min_gap_min`, `days` (дни недели), `tz`, `ramp` (разгон нового аккаунта: старт, дней), `enabled`.
- `group_profile`: группа -> профиль; `default_profile` для остальных.
- `overrides`: аккаунт -> `profile`, `posts_per_day`, `paused`.

`infra/files/plan/<слот>.json` (по файлу на слот, чтобы параллельные воркфлоу не мешали друг другу): скользящий горизонт 24-36 часов. Слот: `id`, `account`, `at`, `state` (`planned`, `preparing`, `prepared`, `publishing`, `done`, `skipped`, `failed`), `reason`.
Подготовленные ролики: `infra/files/prepared/<слот>/` (итоговое видео и `meta.json` с хуком, подписью, хэштегами, музыкой).

## Воркфлоу
1. **06 Scheduler tick** (раз в минуту): строит недостающие слоты (планировщик), выдаёт слоты на подготовку (по одному-двум, ffmpeg нагружает процессор), выдаёт готовые слоты на публикацию (не больше `max_parallel`), помечает слишком опоздавшие слоты как `skipped`.
2. **07 Prepare slot**: берёт следующее видео из запаса этого аккаунта, готовит итоговый ролик.
3. **08 Publish slot**: проверка токена, загрузка в TikTok, архивация папки ролика в `done`, запись в журнал.
Существующий воркфлоу 04 остаётся для ручной публикации («Publish videos»).

## Защиты
- Общая пауза и пауза аккаунта. Автопауза аккаунта после нескольких ошибок подряд.
- Системные ошибки (не подключён, истёк вход, ограничения приложения) останавливают аккаунт, видео остаётся в очереди.
- Ошибки дневных лимитов TikTok: пауза аккаунта до конца дня, а не повторные попытки.
- Оповещение в Telegram: мало видео, истекает вход, аккаунт на автопаузе.

## Панель (вкладка Schedule)
Статус и кнопка паузы всех, лента слотов на сегодня, «следующий пост» у каждого аккаунта, редактор профилей и привязка групп, кнопки «опубликовать сейчас» и «пропустить слот».

## Условия
Работает, пока включены ПК, Docker Desktop и ngrok; отключить спящий режим Windows. Пока приложение TikTok не одобрено, все посты приватные, а аккаунты должны быть закрытыми.
